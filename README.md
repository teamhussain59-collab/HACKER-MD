## 📌 **About HACKER-MD**
**HACKER-MD** is a powerful, fast, and secure WhatsApp bot built with **Node.js** and **Baileys**. It features a multi-device pairing system, AI chat, media downloading, group management, and much more. Designed to be hosted 24/7 on Railway or Render.

<br>

## ✨ **Features**
- ✅ **Pairing Code Login** (No QR needed)
- ✅ **Multi-Account Support** (Run multiple bots)
- ✅ **AI Chat** (Powered by OpenRouter)
- ✅ **Media Downloader** (YouTube, TikTok, Instagram, FB)
- ✅ **Sticker Maker** (Image/Video to Sticker)
- ✅ **Group Admin Tools** (Kick, Promote, Tagall, Antilink)
- ✅ **Islamic, Anime, Fun & Utilities** commands
- 🚫 **No OTP / Movie features** (Safe & Clean)

### 🔧 **Environment Variables**
| Variable | Description | Required |
| :--- | :--- | :--- |
| `OWNER_NUMBER` | Your WhatsApp number (e.g., 92300...) | ✅ Yes |
| `PAIR_NUMBERS` | Bot's WhatsApp number (comma separated) | ✅ Yes |
| `PREFIX` | Command prefix (default: `.`) | ❌ No |
| `MODE` | `public` or `private` | ❌ No |
| `OPENROUTER_API_KEY` | For AI commands | ❌ Optional |
